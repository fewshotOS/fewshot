# R1 — Policy core

labels: roadmap, runtime, R1

## Goal
Labels, value table, gate, outbox and approvals as portable Rust crates.

## Tasks
- [ ] `libs/labels`: secrecy tags, integrity levels incl. `bounded`, join / flow rules
- [ ] `labeld` value table with handles (ADR-0005)
- [ ] `gate`: capability check, integrity floors, egress clearances, outbox, structured refusals
- [ ] Digest-bound, signed, single-use approvals (ADR-0006)
- [ ] Host-abstraction layer so crates also build for seL4

## Acceptance criteria
- [ ] I1–I5 invariant suites green on Linux
- [ ] Gate never reads labels from the caller
- [ ] A modified argument invalidates its approval
