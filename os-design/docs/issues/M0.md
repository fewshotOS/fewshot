# M0 — Boot

labels: roadmap, os, M0

## Goal
seL4 + root task + supervisor boot on QEMU and start components from a manifest.

## Tasks
- [ ] Set up `rust-sel4` build for x86_64 and aarch64
- [ ] QEMU runner script under `tools/`
- [ ] Root task hands initial capabilities to `supervisor`
- [ ] `supervisor` parses a minimal system manifest and starts components with only the capabilities listed
- [ ] Serial console logging
- [ ] CI job that builds the image and boots it in QEMU

## Acceptance criteria
- [ ] CI boots both architectures in QEMU and asserts expected log lines
- [ ] A component not listed in the manifest cannot be started
- [ ] A faulting test component is restarted by the supervisor
