# P0 — Hosted policy-engine prototype on Linux

labels: roadmap, prototype

## Goal
Prototype the gate, labels and agent executor as an ordinary Rust library on Linux, so the policy engine and prompt-injection tests mature before the OS can run them.

## Tasks
- [ ] `libs/labels`: secrecy tag sets, integrity levels, join / flow rules
- [ ] `libs/gate`: capability check, integrity floors, egress clearances, outbox, structured refusals
- [ ] Plan DSL interpreter with per-value label tracking
- [ ] Planner / quarantined reader split against a local model
- [ ] Adversarial stub planner and reader that always follow injected instructions
- [ ] AgentDojo-style injection benchmark harness

## Acceptance criteria
- [ ] With adversarial stubs, zero policy-violating effects execute without approval
- [ ] The same crates compile for the seL4 target unchanged once M1 lands

## Depends on
None — runs in parallel with M0–M1
