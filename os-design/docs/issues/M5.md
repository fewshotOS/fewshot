# M5 — Inference

labels: roadmap, os, M5

## Goal
`infer` service with one local model and priority scheduling.

## Tasks
- [ ] Model registry with signed, content-addressed weights
- [ ] llama.cpp backend in the Linux VM with accelerator passthrough
- [ ] Grammar-constrained decoding from Cap'n Proto schemas
- [ ] Priority classes with preemption at token boundaries
- [ ] Labeled KV-cache objects; output label = join of inputs
- [ ] Call records and `replay`

## Acceptance criteria
- [ ] Interactive latency SLO met under background load
- [ ] Outputs always match the requested grammar
- [ ] Replay reproduces a recorded call
- [ ] Remote routing is blocked by `egress` without clearance
