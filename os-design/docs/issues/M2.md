# M2 — State

labels: roadmap, M2

## Goal
Versioned typed store, transactions and hash-chained audit log.

## Tasks
- [ ] `store`: content-addressed CoW objects, typed by schema, with labels and provenance fields
- [ ] `store.update` with version-checked writes (`stale` result)
- [ ] `txn`: begin / diff / commit / abort on a branch
- [ ] `audit`: append-only hash-chained log
- [ ] POSIX view prototype (read-only is fine)

## Acceptance criteria
- [ ] Crash-consistency tests (power loss mid-commit)
- [ ] Abort leaves no trace in the store
- [ ] Stale writes are refused and return the current version
- [ ] Audit chain verification detects tampering
