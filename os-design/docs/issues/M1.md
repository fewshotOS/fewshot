# M1 — RPC

labels: roadmap, M1

## Goal
Cap'n Proto RPC over seL4 endpoints with capability passing.

## Tasks
- [ ] Cap'n Proto transport over seL4 IPC + shared memory
- [ ] Code generation from `interfaces/` into Rust crates
- [ ] Map interface references to endpoint capabilities
- [ ] Capability transfer between components in RPC calls

## Acceptance criteria
- [ ] Round-trip RPC tests between two components
- [ ] A capability passed in a call is usable by the receiver and revocable by the sender
- [ ] A component without the reference cannot call the interface
