# R3 — MCP release

labels: roadmap, runtime, R3

## Goal
First usable release on Linux, Windows and macOS.

## Tasks
- [ ] MCP-compatible server exposing gated actions
- [ ] Approval app as a separate privileged process with plain-language templates and batching
- [ ] Audit timeline viewer
- [ ] Builds and installers for Linux, Windows, macOS
- [ ] Approval-rate telemetry (local only, opt-in)

## Acceptance criteria
- [ ] Existing MCP clients can use gated actions without changes
- [ ] ≤ 3 approval prompts per hour of typical use in dogfooding
- [ ] Docs state plainly what the runtime cannot guarantee on a host OS
